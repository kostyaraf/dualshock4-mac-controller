# ds4mouse

Управление Mac геймпадом DualShock 4 вместо мыши. Работает и с клонами, и с другими геймпадами, которые видит macOS (Xbox, DualSense). Тачпад есть только у DualShock.

## Запуск

```sh
swift build -c release
.build/release/ds4mouse          # работать
.build/release/ds4mouse test     # только показывать нажатия, курсор не трогать
```

При первом запуске macOS попросит доступ: «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Его нужно дать приложению, из которого запускаете программу (например, Терминалу).

## Постоянная работа

```sh
./scripts/install.sh     # собрать, включить автозапуск при входе и перезапуск при сбое
./scripts/uninstall.sh   # выключить и убрать автозапуск
```

Лог: `~/Library/Logs/ds4mouse.log`. После установки нужно один раз разрешить `ds4mouse` в «Универсальном доступе».
После каждой переустановки разрешение, скорее всего, придётся выдать заново: macOS привязывает его к конкретной сборке программы.

## Раскладка по умолчанию

| Что | Действие |
|---|---|
| Левый стик | курсор: медленно в центре, быстро у края; если держать у края дольше 0,3 с — разгоняется до ×4; если долго вести медленно (прицеливаться) — ещё чуть замедляется |
| Правый стик | прокрутка (плавно в центре, у края быстрее, если держать — разгоняется); если левый стик уже ведёт курсор — ускоряет его (до ×4.5) |
| R2 | Backspace (держать — стирает подряд, после 1,5 с — словами; PS + R2 — до начала строки) |
| L1 | сама по себе пока свободна |
| Тачпад, смахнуть 1 или 2 пальцами | как 4 пальца на трекпаде Mac: вверх — Mission Control, вниз — окна приложения, влево/вправо — соседний рабочий стол |
| Нажатие тачпада | пробел; два быстрых нажатия — новая строка без отправки (терминал: Option+Enter, остальное: Shift+Enter); держать — экранная клавиатура (стик — выбрать, ✕ — ввод, □ — Shift, △ — RU/EN/123, ○ — закрыть); двумя пальцами — правый клик |
| Крестик | левый клик (удержание — перетаскивание) |
| Круг | правый клик |
| Квадрат | переключить приложение (⌘Tab) |
| Треугольник | Escape |
| L2 / R1 | Tab / Return |
| R3 | средний клик |
| Крестовина | стрелки |
| Share | скриншот экрана в буфер обмена (PS + Share — скриншот окна: кликнуть по окну) |
| Options | Return |
| PS | правый Cmd (например, для голосового набора). PS + L2 — Cmd+Tab (приложения), PS + L1 — Cmd+` (окна приложения). PS + Квадрат / Круг / Треугольник / R3 — копировать / вставить / вырезать / выделить всё |
| L3, держать 1 с | пауза (подсветка зелёная — работает, оранжевая — пауза) |

## Настройка

```sh
.build/release/ds4mouse init-config   # создаёт ~/.config/ds4mouse/config.json
```

В файле можно оставить только то, что меняете, остальное возьмётся по умолчанию:

```json
{
  "cursor": { "speed": 1200 },
  "buttons": { "square": "key:cmd+shift+t", "ps": "toggleEnabled" }
}
```

Действия: `leftClick`, `rightClick`, `middleClick`, `toggleEnabled`, `newLine`, `screenshotScreen`, `screenshotWindow`, `none`, `key:<модификаторы+клавиша>` (модификаторы `cmd ctrl alt shift fn`).
Кнопки: `cross circle square triangle l1 r1 l2 r2 l3 r3 share options ps touchpad dpadUp dpadDown dpadLeft dpadRight`.

Вместо жестов можно вернуть курсор одним пальцем и прокрутку двумя: `{"touchpad": {"oneFingerMode": "cursor", "twoFingerMode": "scroll"}}`.
Жестам можно назначить свои действия: `{"touchpad": {"swipes": {"down": "key:cmd+w"}}}`.
Жесты работают через сочетания Ctrl+стрелки, они должны быть включены в «Системные настройки → Клавиатура → Сочетания клавиш → Mission Control».

Почему раскладка именно такая — в [SPEC.md](SPEC.md).

## Устройство кода

- `Input/` — чтение геймпада. Кнопки и стики берутся через системную поддержку геймпадов (`GameController`), пальцы на тачпаде — напрямую из пакетов DualShock (`DS4RawReader`).
- `Output/` — виртуальные мышь и клавиатура.
- `Mapping/` — настройки и действия кнопок.
- `Engine/` — 125 раз в секунду читает состояние геймпада и превращает его в действия.

Новый источник ввода (гироскоп, другой геймпад) добавляется в `Input/` и заполняет `ControllerState`. Новое действие добавляется в `Action` и в `Engine.perform`.

## Что не работает

- **Микрофон и разъём для наушников** — macOS не видит их по Bluetooth.
- **Кнопка PS** — macOS по умолчанию открывает по ней приложение «Игры». Отключено командой `defaults write com.apple.GameController bluetoothPrefsMenuLongPressAction -integer 0`, вернуть — `defaults delete com.apple.GameController bluetoothPrefsMenuLongPressAction`.
