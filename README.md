# ds4mouse

Управление Mac геймпадом DualShock 4 вместо мыши. Работает и с клонами, и с другими геймпадами, которые видит macOS (Xbox, DualSense). Тачпад есть только у DualShock.

## Запуск

```sh
swift build -c release
.build/release/ds4mouse          # работать
.build/release/ds4mouse test     # только показывать нажатия, курсор не трогать
```

При первом запуске macOS попросит доступ: «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Его нужно дать приложению, из которого запускаете программу (например, Терминалу).

## Постоянная работа

```sh
./scripts/install.sh     # собрать, включить автозапуск при входе и перезапуск при сбое
./scripts/uninstall.sh   # выключить и убрать автозапуск
```

Лог: `~/Library/Logs/ds4mouse.log`. После установки нужно один раз разрешить `ds4mouse` в «Универсальном доступе».
После каждой переустановки разрешение, скорее всего, придётся выдать заново: macOS привязывает его к конкретной сборке программы.

## Раскладка по умолчанию

| Что | Действие |
|---|---|
| Левый стик | курсор |
| Правый стик | прокрутка |
| L2 / R2 (плавно) | медленнее, для точности / быстрее |
| Тачпад, 1 палец | курсор, как на трекпаде |
| Тачпад, 2 пальца | прокрутка |
| Нажатие тачпада | клик (двумя пальцами — правый клик) |
| Крестик | левый клик (удержание — перетаскивание) |
| Круг | правый клик |
| Квадрат | переключить приложение (⌘Tab) |
| Треугольник | Mission Control |
| L1 / R1 | назад / вперёд (⌘[ / ⌘]) |
| R3 | средний клик |
| Крестовина | стрелки |
| Share / Options | Escape / Return |
| PS | правый Option (например, для голосового набора) |
| L3, держать 1 с | пауза (подсветка зелёная — работает, оранжевая — пауза) |

## Настройка

```sh
.build/release/ds4mouse init-config   # создаёт ~/.config/ds4mouse/config.json
```

В файле можно оставить только то, что меняете, остальное возьмётся по умолчанию:

```json
{
  "cursor": { "speed": 1200 },
  "buttons": { "square": "key:cmd+shift+t", "ps": "toggleEnabled" }
}
```

Действия: `leftClick`, `rightClick`, `middleClick`, `toggleEnabled`, `none`, `key:<модификаторы+клавиша>` (модификаторы `cmd ctrl alt shift fn`).
Кнопки: `cross circle square triangle l1 r1 l2 r2 l3 r3 share options ps touchpad dpadUp dpadDown dpadLeft dpadRight`.

## Устройство кода

- `Input/` — чтение геймпада. Кнопки и стики берутся через системную поддержку геймпадов (`GameController`), пальцы на тачпаде — напрямую из пакетов DualShock (`DS4RawReader`).
- `Output/` — виртуальные мышь и клавиатура.
- `Mapping/` — настройки и действия кнопок.
- `Engine/` — 125 раз в секунду читает состояние геймпада и превращает его в действия.

Новый источник ввода (гироскоп, другой геймпад) добавляется в `Input/` и заполняет `ControllerState`. Новое действие добавляется в `Action` и в `Engine.perform`.

## Что не работает

- **Микрофон и разъём для наушников** — macOS не видит их по Bluetooth.
- **Кнопка PS** — macOS может перехватывать её сама (открывает приложение «Игры»). Это отключается в «Системные настройки → Игровые контроллеры».
