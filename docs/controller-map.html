DS4Mouse — карта управления

обновлено: 2026-11-05

L2 — Tab

Options + L2 — переключить приложение (Cmd+Tab): держи Options, жми L2, отпусти Options — выбрано

L1 — не назначена

Options + L1 — следующее окно того же приложения (Cmd+`)

Share — скриншот экрана

Весь экран в буфер обмена, вставить — Cmd+V

Options + Share — скриншот окна: кликни крестиком по окну

Крестовина — стрелки

Держать — повтор

Options + ↓ копировать · → вставить · ↑ вырезать · ← выделить всё

Левый стик — курсор

  • малый наклон — медленно и точно
  • долго ведёшь медленно — ещё медленнее (прицеливание), паузы до 3 с не сбрасывают
  • у края — быстро; упёр в край > 0,3 с — разгон до ×4
  • L3 держать 1 с — пауза / продолжить

Тачпад

Смахнуть двумя пальцами (одним — ничего): ↑ Mission Control · ↓ окна приложения · ← → соседний стол

Продавить — пробел · 2× быстро — новая строка без отправки · держать 0,6 с — экранная клавиатура · двумя пальцами — правый клик

PS — пока не назначена

R2 — Backspace

Держать — стирает подряд, через 1,5 с — словами

Options + R2 — стереть до начала строки

R1 — Enter

Options — Cmd

Держи и жми другую кнопку: Options + кнопка = Cmd + её действие. Это правый Cmd, на нём диктовка.

Правые кнопки

△ Escape   □ Enter   ○ правый клик

✕ левый клик: держать — перетащить, 2× — выделить слово, 3× — строку

Правый стик — прокрутка

Медленно в центре, у края быстрее, упёр в край — разгон.

Если левый стик уже ведёт курсор — ускоряет курсор.

R3 — средний клик

Экранная клавиатура (тачпад держать 0,6 с)

Левый стик / крестовина — выбрать клавишу · ✕ ввести · □ заглавная · △ RU → EN → 123 · ○ закрыть

Пробел, новая строка (тачпад), Backspace (R2), Enter (R1) и прокрутка работают как обычно. Курсор мыши стоит.

Сочетания с Options (= Cmd)

+ L2 — приложения · + L1 — окна приложения

+ ↓ копировать · + → вставить · + ↑ вырезать · + ← выделить всё

+ Share — скриншот окна · + R2 — стереть строку
